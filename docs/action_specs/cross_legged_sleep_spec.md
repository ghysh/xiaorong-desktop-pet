# 盘腿坐下、睡眠与起身规范草案

## 完整流程

```text
IDLE -> SIT_DOWN -> SLEEPING -> WAKE_UP -> IDLE
```

这四个是高层行为概念；具体内容由 `sit_down_cross_legged`、`sleep_cross_legged_loop`、`wake_up_cross_legged` 三个剪辑表达。不能把每一帧或每个方向加成 `PetState`。

## 素材预算

| 剪辑 | 建议帧数 | FPS | 循环 |
|---|---:|---:|---|
| 坐下 | 6～10 | 8～12 | 一次，末帧保持 |
| 盘腿睡眠 | 4～8 | 4～8 | 慢循环 |
| 醒来起身 | 6～10 | 8～12 | 一次 |

坐下阶段要展示重心降低、双腿交叠和裙摆重新遮挡；睡眠阶段闭眼、慢呼吸、头部轻微下垂；起身阶段必须回到正式站立比例和脚底锚点。不能压扁/旋转站立图、用黑影代替腿、隐藏未完成结构或裁掉鞋子。

## 身份保持

- 保留完整长发、刘海、粉紫眼睛/闭眼对应关系、双手、深色裙装、长袜、鞋和背包。
- 明确哪条腿在前、裙摆如何覆盖、手放在何处；帧间不交换左右关系。
- 红色发饰、肩带、腰带、裙边等不对称元素必须连续。
- 睡眠呼吸幅度低于普通待机，不持续大幅摇摆。

## 唤醒与打断

- 拖拽：最高用户抢占，立即退出睡眠意图；播放器安全取消，窗口立即归用户。
- 单击：请求唤醒；不播放普通点击挤压，转入起身流程。
- 提醒：默认排队到安全唤醒点；若提醒已逾期较多，可先触发起身再展示，绝不覆盖拖拽。
- 用户选择舞蹈：先执行起身；若允许快速起身，也必须使用经审核剪辑，不能瞬间换站立图。
- 退出/暂停：退出打断一切；暂停冻结当前安全帧和计时。
- 睡眠中禁用普通眨眼；完成起身并回到待机后重新安排眨眼。

本阶段不新增 `SIT_DOWN`、`SLEEPING` 或 `WAKE_UP` 运行状态，不生成坐姿图片。

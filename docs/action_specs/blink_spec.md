# 自主眨眼素材规范草案

## 素材策略

优先使用局部透明眼部覆盖层，不重绘整个人物。正式母版保持不变；覆盖层在统一 1024 × 1536 画布坐标中对齐，运行时按现有 keep-aspect 规则映射到三档尺寸。

根据当前方案 B 的倾斜头部，待 10B 像素级复核的建议覆盖区域为源画布 `x=360..535, y=185..300`。左右眼不能按水平线机械对齐，刘海遮挡、上睫线、粉紫虹膜、脸部阴影必须分别匹配。该区域只是制作边界草案，不是已批准的眼睑造型。

| 显示尺寸 | 建议覆盖矩形（约值） |
|---|---|
| 240 × 360 | x 84～125，y 43～70 |
| 280 × 420 | x 98～146，y 51～82 |
| 320 × 480 | x 113～167，y 58～94 |

10B 必须由源坐标实时等比映射并做 Alpha 叠加诊断，不能硬编码三套彼此漂移的坐标。

## 帧与时间

自然眨眼建议 5 个视觉阶段：全开、闭合约 40%、完全闭合、回升约 40%、恢复全开。总时长 140～220 ms，建议关键帧时长约 35/30/35/30/35 ms，再通过播放器按实际美术帧调整。

触发间隔使用专属 `random.Random`：3～8 秒。偶尔双眨，第二次间隔 80～160 ms。随机数只在安排下一次眨眼/双眨时消费；固定 seed 必须复现，不得每个绘制帧取随机数。

## 打断与暂停

- 拖拽、暂停、停止、舞蹈、行走转身、坐下/睡眠/起身均暂停或立即取消普通眨眼。
- 睡眠闭眼期间不得调度眨眼。
- 点击反馈优先于眨眼；被打断的眨眼不强制补播。
- 普通待机恢复后重新安排 3～8 秒，而非立刻眨眼。

## 禁止变化与待确认

不得改变粉紫虹膜色、瞳孔大小关系、深色上睫线、刘海遮挡、面颊阴影或温和表情。需要用户确认：闭眼弧线形状、睫线厚度、是否保留少量下睫线、双眨频率和闭眼时刘海遮挡处理。本阶段不绘制任何闭眼帧。

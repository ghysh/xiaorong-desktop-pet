# 动作范围建议（第二阶段草案）

> 状态：**草案，待用户选择**。以下仅定义后续制作范围；本阶段没有制作动作帧、角色素材、窗口或互动逻辑。

## 前提与约束

- 可用视觉依据仅为一张 346 × 346 上半身近景。
- 主体接近或触及画布左右与下边缘，完整身体结构不可确认。
- 深色不对称长发、粉紫大眼睛、柔和表情、深色服装与红色点缀为主要一致性约束。

## 一级动作：低改动

| 动作 | 后续实现思路 | 形象风险 | 观察依据与确定程度 |
| --- | --- | --- | --- |
| 轻微呼吸 | 整体纵向缩放或局部极轻形变 | 低 | 当前为近景静态图；高 |
| 上下浮动 | 整体位移 | 低 | 不改变角色像素；高 |
| 左右轻晃 | 小角度整体旋转 | 低 | 可保持面部和发丝关系；高 |
| 拖拽倾斜 | 与拖拽方向相关的整体倾斜 | 低 | 不需要补绘；高 |
| 点击缩放 / 落地弹性 | 短暂整体缩放与位移 | 低 | 不需要新角色素材；高 |

这些动作不应改变 A 级外轮廓、眼部比例、红色点缀与深浅关系。

## 首版候选方案

### 方案 1：保守首版

- 动作清单：轻微呼吸、上下浮动、左右轻晃、拖拽倾斜、点击缩放、落地弹性。
- 素材需求：经确认的一张透明基础角色图；不新增局部动作帧。
- 开发复杂度：低。
- 视觉风险：低；不涉及未知的画外身体结构。
- 适用场景：优先验证稳定桌宠体验与窗口交互。

### 方案 2：均衡首版

- 动作清单：方案 1 加眨眼、一个轻微表情变化和一个点击情绪反馈。
- 素材需求：透明基础角色图 + 约 4–6 个经审核的局部状态/覆盖层。
- 开发复杂度：中。
- 视觉风险：中；眼部、刘海、手部遮挡须保持一致。
- 适用场景：用户确认局部重绘规范后，希望提升角色生命感。

### 方案 3：丰富首版

- 动作清单：方案 2 加行走、跳跃、坐下/睡觉、转身或攀边。
- 素材需求：完整角色设定、分层文件和约 24–48+ 张关键帧/中间帧，具体取决于帧率与动作数量。
- 开发复杂度：高。
- 视觉风险：高；单张近景不足以保证全身、侧背面和动态服装的一致性。
- 适用场景：已完成角色设定与多角度素材后。

## 推荐方案

推荐**方案 1：保守首版**。依据是原图为单张、近景、RGB 且主体触边的视觉参考；该方案可最大限度保持现有身份特征，并把局部/完整重绘风险留到用户确认视觉规范之后。

该推荐的确定程度为高，但最终方案为**待用户确认**。

## 待用户选择事项

1. 选择方案 1、2 或 3 作为首版动作范围。
2. 是否允许后续制作眨眼和表情的局部补绘。
3. 是否允许后续为完整动作建立画外身体、全身和侧背面设计。
4. 对重绘一致性（严格复刻 / 可接受适度风格化）的容忍度。

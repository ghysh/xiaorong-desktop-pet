# Desktop Pet 1.0.0 使用说明

## 系统要求与启动

推荐 Windows 10 或 Windows 11 64 位。解压 `DesktopPet-1.0.0-win64-portable.zip`，保留完整 `DesktopPet` 文件夹，然后双击 `DesktopPet.exe`。程序未进行数字签名；首次运行可能出现未知发布者或安全软件提示，请只使用本项目提供并核对 SHA-256 的发布包。

## 操作

- 左键单击角色可见区域：播放轻微的 260 ms 反馈；透明留白不会触发反馈。
- 左键拖拽：移动桌宠；超过 Windows 系统拖拽阈值后不会误触发单击。
- 右键：打开与托盘共享的菜单。
- 托盘菜单：显示/隐藏、暂停/恢复动画、尺寸、始终置顶、设置、重置位置和退出。
- 三档尺寸：240 × 360、280 × 420、320 × 480。
- 设置：可切换置顶、动画、自动待机状态、单击反馈和位置记忆。
- 重置位置：将桌宠移到当前鼠标屏幕可用区域的右下角。
- 完全退出：选择“退出桌宠”；仅隐藏窗口不等于退出。

## 配置和崩溃日志

设置保存在 Qt 用户配置目录下的 `DesktopPet/settings.ini`，通常位于 `%LOCALAPPDATA%\DesktopPetProject\DesktopPet\settings.ini`。崩溃日志通常位于 `%LOCALAPPDATA%\DesktopPetProject\DesktopPet\logs\`，仅保留最近 10 个，不上传网络。

## 已知限制

透明像素仍会阻挡下层窗口鼠标；没有真正像素穿透、自动移动、行走、跳跃、眨眼、表情帧、对话、音效、开机启动或自动更新。应用未数字签名，不保证支持 Windows 10/11 之外的系统。

## 删除便携版

先从菜单完全退出，再删除整个 `DesktopPet` 发布文件夹。用户设置仍保留在上述 AppConfigLocation；若需完全清除，可由用户手动删除对应 `DesktopPet` 设置目录和本地日志目录。删除发布文件夹不会删除项目源码或角色母版。

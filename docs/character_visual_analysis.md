## 分析方法

## 当前原图局限与风险

1. 单张 346 × 346 近景无法提供完整身体、鞋袜和背面结构。
2. 主体触及左右及下边缘，无法直接扩展成全身动作画布。
3. RGB 无 Alpha，浅色区域与近白背景使自动阈值抠图不可靠。
4. 手部、刘海、发丝和服装遮挡关系使局部补绘的连续性风险偏高。

## 推荐路线

先由用户确认 A 级特征、默认尺寸、背景路线和可接受的重绘范围；之后以方案 B 建立经人工审核的透明基础，再决定是否向方案 D 的局部/完整重绘扩展。此建议不代表本阶段已经处理背景或绘制素材。

# Desktop Pet 1.0.0 release scope freeze

Version 1.0.0 is feature-frozen for final testing and Windows portable packaging.

Included: the approved Plan B full-body character, transparent frameless window, always-on-top mode, manual dragging, low-risk idle animation, deterministic state machine, Alpha-aware click feedback, shared window/tray menus, system tray, three display sizes, animation/behavior/click toggles, remembered position with screen recovery, settings dialog, reset position, and normal terminal exit.

Excluded: automatic movement, walking, running, jumping, cursor following, screen-edge climbing, blinking or expression frames, dialogue, sound, startup registration, networking, online updates, and true transparent-pixel pass-through.

Only release blockers—crashes, data loss, missing resources, broken packaging, incorrect paths, configuration failure, or exit/process leakage—may change runtime code in Stage 10. Other observations belong in `known_issues_1.0.0.md`.
